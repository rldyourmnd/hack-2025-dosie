# Source maintenance

This repository retains a hackathon browser demo, profiles/network data and supporting
documents. Source CI maintenance preserves those files; it does not evaluate their
claims, rewrite scoring, launch the site, apply generated policy or use cloud/model
credentials.

`just check` is the offline command/workflow gate. `just verify` also runs the
accepted-source full-history secret scan on the CI executor. There is no application
package build or test recipe. Shared CI prepares the declared exact native tools;
keep dependency/tool values with their normal owning updater and asset manifest.

Preserve unrelated source/history/branches and document data. A source check does not
establish remote-link, account, investor-fact, visual/browser or runtime acceptance.
